Caveats & Method

  • Postage decides everything. Most sellers are Japan-based. A AU$332 club with AU$135 postage is a AU$467 club. Filter by landed cost, or restrict to free-delivery listings.
  • Regular flex is scarce. The eBay facet filter for “Regular” is unreliable — verify flex in the listing title text. Many near-identical listings are Stiff or Ladies.
  • Failures preserved. Several searches returned eBay HTTP 403 blocks during this run: the m4 irons regular query and the m2 wedge query both failed, so there is no M4-single-iron-regular or M2-wedge pricing from those angles. Every listing above came from a fetch that returned HTTP 200.
